# 📊 Customer Support SLA Tracker Dashboard

## 📌 Project Overview
An interactive Excel dashboard designed to track customer support SLA compliance, ticket distribution by category, and average resolution status.

## 🛠️ Key Features
- **KPI Summary Cards:** Quick view of Total Tickets, SLA Breached, and Closed Tickets.
- **Interactive Slicers:** Dynamic filtering across all charts by `Issue Category` and `SLA Status`.
- **Data Visualizations:**
  - **Donut Chart:** SLA Status breakdown (Closed vs SLA Breached).
  - **Horizontal Bar Chart:** Ticket volume distribution across issue categories.
  - **Column Chart:** Resolution status breakdown.

## 📂 Architecture
- **Raw Data:** Base ticket logs and resolution details.
- **Pivot_Calc:** Backend pivot tables powering the visual analytics.
- **Dashboard:** Clean, gridless UI layer for reporting.
